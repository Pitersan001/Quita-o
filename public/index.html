Dúvidas frequentes

Este é o site oficial do Itaú?

Não. Esta página oferece orientação independente e não pertence, não representa e não é operada pelo Itaú Unibanco. Para operações e informações oficiais, utilize os canais publicados pelo próprio banco.

O site consulta meu contrato diretamente?

Não. O formulário apenas prepara uma mensagem para atendimento. Não acessamos sistemas bancários nem consultamos saldo, parcelas ou dados internos do banco.

Existe desconto garantido para quitar o financiamento?

Não há desconto garantido. Qualquer valor, abatimento ou condição precisa ser calculado e confirmado diretamente pela instituição credora.

Preciso informar senha ou código do banco?

Não. Nunca informe senha, token, código recebido por SMS, número completo de cartão ou credenciais bancárias neste formulário ou por WhatsApp.
